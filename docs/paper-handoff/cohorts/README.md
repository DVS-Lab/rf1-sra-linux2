# Final Paper Cohorts

Jacob supplies `katie-final.tsv` here through Git when the final survey/linkage
cohort has been intersected with the settled 121-pair imaging selection.

Use exactly one column headed `subject`, one unique RF1 ID per row, in intended
analysis order. No names, dates of birth, or raw survey records are needed. This
directory intentionally does not contain a guessed final roster.

The [bundle runbook](../../socialdoors-randomise-bundle.md) explains the validation,
output paths, and separate information needed for a final statistical design.
